## 学到的（用自己的话写）

- **Git 三区域**：工作区（正在改的文件）→ 暂存区（add，这次要交的清单）→ 版本库（commit，本地存档）。
  commit 只存本地，要传 GitHub 必须再 push。
- **Windows 上 javac 必须加 `-encoding UTF-8`**：否则源码里的中文会报「编码 GBK 的不可映射字符」。
- **在 IDEA 里运行不要手动建配置**，直接点 main 方法左边行号旁的绿色 ▶，会自动生成。
  「未指定模块」说明 Maven 项目还没被 IDEA 识别，右键 pom.xml → 添加为 Maven 项目即可。
- **运行配置里「存储为项目文件」不勾**，那是把配置提交进 git 的选项。
- **commit message 前缀**：feat 新功能 / fix 修 bug / docs 文档 / chore 配置杂项 / refactor 重构。
  给配置文件用 feat 会被笑。
- Git Bash 是给你敲 Linux 命令的窗口；现在用 IDEA 的图形界面（Ctrl+K / Ctrl+Shift+K / Alt+9）就够了。

## 卡住的地方 + 怎么解决的

- **IDEA 运行配置显示「未指定模块」** → Maven 项目没被识别为模块，
  右键 pom.xml →「添加为 Maven 项目」，等索引跑完就好了。
- **提交窗口只有一个 vcs.xml** → 正常，因为其他文件已在命令行提交过，
  IDEA 只显示「上次提交之后的变化」，运行程序不会改代码。
- **PowerShell 里 `java -Dfile.encoding=UTF-8` 报「找不到主类」** → 加引号即可。
- **git status 中文路径显示成 \347\254\224...** → `git config --global core.quotepath false` 解决。
