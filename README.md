# learning-log

后端 + AI 应用工程方向的学习日志。目标：2027 年 2 月拿到第一份实习。

- 起点：2026-10-08（大三上）
- 主线：Java 后端为底座，Spring AI / RAG 为差异化
- 节奏：学期内每天 ≤ 3 小时，假期 5–6 小时

## 目录约定

```
learning-log/
├── README.md          本文件
├── 日志/              每天一篇，文件名 = 日期
├── 笔记/              按模块整理的技术笔记（八股、源码、踩坑）
└── 项目/
    ├── short-link/    项目 1：短链接平台 + AI 摘要
    └── rag-kb/        项目 2：企业知识库 RAG 问答
```

## 每天日志模板

```markdown
# 2026-10-08

## 今天做了什么

## 学到的（用自己的话写，不要抄）
-

-

- 

## 自检
- [ ] 今天的代码都 commit 了吗
- [ ] 关掉 AI，今天学的东西我能讲出来吗
```

## 三条铁律

1. **不复习等于白学**：每天开始先花 20 分钟看昨天的笔记。
2. **判断学会的唯一标准**：关掉 AI，能把这个知识点讲清楚、写出来。
3. **落后别推翻计划**：落后一天就第二天接上，重来是最常见的失败方式。
